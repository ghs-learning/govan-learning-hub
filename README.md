# Govan Learning Hub

Public learning resources for Govan High School. 22 subject hubs, Parent Zone and staff learning resources.

Open the GitHub Pages link to use the hub. Original CLPL and Digital Pedagogy designs are kept separate from the main hub styles. No pupil accounts or class lists are included. Personal learning reviews remain on the device.

## Updating resources
Use the Content workspace in the hub to prepare a draft and download additions.js. Replace the additions.js file in this repository to publish approved resources, news and policy links. Existing course materials remain separate from shared navigation and accessibility controls.

BGE investigations and new subject material need departmental review. The original dated staff programme remains as supplied.
